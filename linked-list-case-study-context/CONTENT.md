## Why a Linked List?

A linked list represents a sequence using nodes connected through
links/references.

For this learning scenario, it provides a clear model for: - adding
elements - removing elements - connecting elements - following the
sequence

Do not oversell the structure. Mention that searching still requires
traversal and that arrays can be preferable when direct indexing is
important.

------------------------------------------------------------------------

## Operation Explanations

### Add at End

A new node is connected after the current final node.

### Insert in Middle

The new node is connected between two existing nodes.

### Delete

The surrounding link is changed so the removed node is no longer part of
the route.

### Search

Start at the head and check each node until the target is found or the
list ends.

### Traverse

Visit each node from head to null in sequence.

------------------------------------------------------------------------

## Real-World Applications

### Music Playlist

Songs form a sequence. Each song contains information such as title,
artist, and duration.

### Train Carriages

Carriages can be connected, inserted, removed, and displayed as a
sequence.

### Browser History

Visited pages can be represented as linked elements in a browsing
sequence.
