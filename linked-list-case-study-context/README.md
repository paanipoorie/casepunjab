# Linked List Case Study --- Interactive Educational Website

## Purpose

Build a polished, interactive educational website that showcases a
linked-list case study through real-world scenarios.

The primary scenario is **Tim's City Tour**, adapted into a Punjab-based
sightseeing route so that the abstract linked-list operations are easy
to visualize.

The source case study defines: - Tim's route as a sequence of landmarks
connected like a linked list. - Displaying the current route. - Adding a
landmark at the end. - Inserting a landmark in the middle. - Removing a
landmark. - Searching for a landmark. - Traversing the entire route. -
Explaining why a linked list is suitable. - Discussing real-world
applications.

The same source also includes: 1. Music Playlist Organizer 2. Train
Carriage Management 3. Browser History

## Core Principle

This must NOT be a static presentation of a linked list.

Every major operation must be interactive and must modify the actual
in-memory linked-list state.

The visualization, operation history, code explanation, and challenge
state should derive from that same underlying data structure.

## Recommended Experience

1.  Landing / introduction
2.  Tim's Punjab Tour
3.  Interactive Linked List Playground
4.  Add / Insert / Delete / Search / Traverse
5.  Step-by-step operation explanations
6.  Code + memory/pointer visualization
7.  Operation history
8.  Real-world scenarios
9.  Challenge mode
10. Quiz / recap

## Important

Do not invent claims that are presented as facts from the supplied case
study. Punjab locations are an intentional adaptation for the website's
interactive example.
